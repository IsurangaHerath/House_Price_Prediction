# House Price Prediction Using Machine Learning

A small, reproducible regression pipeline that predicts **historical California
census block-group median house values** from Scikit-learn's California Housing
dataset. Built as a learning project and portfolio entry for Data Science
interview preparation.

> Important limitation: the target is the **historical (1990 Census) district
> median**, *not* current individual-house sale prices and *not* the market
> value of any particular property. Interpret any predicted price with that
> caveat. See [`data/README.md`](./data/README.md) for full context.

## Setup

1. Create a virtual environment and install dependencies:

   ```powershell
   python -m venv .venv
   .venv\Scripts\python.exe -m pip install --upgrade pip
   .venv\Scripts\python.exe -m pip install -r requirements.txt
   ```

2. Activate when ready to develop:

   ```powershell
   .venv\Scripts\Activate.ps1
   ```

## Reproducibility

- Dataset: California Housing, supplied by Scikit-learn (figshare, `cal_housing.tgz`)
- Python version, pinned package versions, random seeds, train/test split config,
  cross-validation settings, and model parameters are documented in
  `reports/reproducibility.md` once the experiments complete.
